# Security Policy

This repository is a static portfolio website. It does not intentionally collect, store or process visitor credentials or sensitive data.

## Reporting

If you discover a security issue in this website, please contact the repository owner through the email address listed in `README.md`. Do not include passwords, tokens or other secrets in public issues.

## Lab safety

References to DVWA, Metasploitable2, Nmap and Metasploit describe authorised educational practice only. Vulnerable training systems should be isolated from public networks and used only with explicit authorisation.
