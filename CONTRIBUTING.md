# Contributing

This is a personal portfolio. Suggestions for accessibility, clarity, responsive behaviour or factual corrections are welcome through GitHub Issues.

Before proposing content changes:
- Keep project outcomes factual and verifiable.
- Do not add claims of certifications, employment, successful exploitation or resolved incidents unless they are accurate and supported.
- Never commit credentials, private IP details, personal documents or screenshots containing sensitive information.
- Keep vulnerable lab targets isolated and do not publish instructions that encourage unauthorised testing.
